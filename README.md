# Catch the Moment — вечерний пруд с карпами кои

Интерактивный первый экран на чистом WebGL: пять карпов кои плавают в вечернем пруду,
светящийся планктон расплывается от рыбок и курсора, а по клику падает монетка —
ближайшие карпы плывут её съесть. Музыка и звуки создаются кодом, включаются кнопкой.

**Учебная копия.** Оригинальная идея и дизайн — Марина Бударина,
[Interactive Koi Pond](https://marinabudarina.github.io/koi/). Проект не связан с автором оригинала.
Код написан с нуля; картинки рыбок сгенерированы в Higgsfield; картинки, код, звуки
и тексты оригинала не использовались.

*Study copy. Original idea & design by Marina Budarina
([Interactive Koi Pond](https://marinabudarina.github.io/koi/)). Not affiliated with the original author.
Code written from scratch; fish images generated in Higgsfield; no assets, code, audio or texts from the original were used.*

## Как устроено

- Один файл `index.html`: разметка, стили, код и картинки внутри.
- Каждая рыбка — картинка на сетке 72 × 28, которая гнётся по «позвоночнику» из 73 точек.
- Шёлковые плавники колышутся своей волной и становятся прозрачнее к краям.
- Планктон — 2D-холст под рыбками; он же подсвечивает рыбок.
- Музыка — китайская пентатоника, «струны» по алгоритму Карплуса — Стронга.

Подробное описание дизайна — в [design.md](design.md).
